# mattermatters-talk
Matter Matters Talk

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `workbook.md` | 내용. 글을 고칠 때는 이 파일만 편집한다. |
| `workbook.html` | 틀. 스타일과 동작을 담고, 열릴 때 `workbook.md`를 읽어 화면을 만든다. |

빌드 과정은 없다. `workbook.md`를 저장하고 브라우저를 새로고침하면 반영된다.

## 여는 방법

내용 파일을 따로 불러오기 때문에 `workbook.html`을 더블클릭(file://)하면 열리지 않는다. 다음 중 하나로 연다.

- VS Code의 Live Server 확장으로 `workbook.html` 열기
- 이 폴더에서 `npx serve` 실행 후 안내되는 주소의 `/workbook.html` 열기
- GitHub Pages 주소로 열기

그림·글꼴은 옆 폴더(`../SyncSlide-Matters` 등)를 가리키므로, 이 폴더만 서버로 열면 그림이 빠진다. 그림까지 보려면 한 단계 위 폴더에서 서버를 열고 `/mattermatters-talk/workbook.html`로 들어간다.

## workbook.md 표기 규칙

### 뼈대

```
---
title: 문서 제목            ← 브라우저 탭과 목차 맨 위
---

# PART Ⅰ | 맥락             ← 부. "작은 글씨 | 제목"
목차: Ⅰ 맥락                ← 왼쪽 목차에 보일 이름
부제: 작은 데이터가 놓이는 자리

## 01 장 제목               ← 장. 두 자리 번호로 시작하면 주소가 #c01
목차: 집·전시·동기신호       ← 목차용 짧은 이름 (없으면 장 제목)
키워드: **대표 키워드**, 보조 키워드
회고: 기다리다 | 2025.06.21  ← 있으면 "회고 — 한눈에" 표에 한 줄 추가

## 용어 {#terms}            ← 번호 없는 장은 {#주소}를 붙인다

### 칸 제목                 ← 장 안의 칸
```

`목차:` `부제:` `키워드:` `회고:` 줄은 제목 바로 아래에 빈 줄 없이 붙여 쓴다.

### 이름이 정해진 칸

| 칸 제목 | 동작 |
| --- | --- |
| `### 주제의식 (정리 초안)` | 큰 글씨로 표시. 괄호 안은 꼬리표. 첫 문단이 회고 표에도 들어간다. |
| `### 핵심 내용` | 요점 목록 |
| `### 영상` | `- [제목](유튜브·비메오 주소) — 메모` 를 썸네일 카드로. 비메오는 끝에 `![](썸네일 주소)` 를 붙인다. |
| `### 기본 정보` | 늘 펼쳐 둔다. |
| `### 파일` | `- ../경로 (메모)` 는 링크, 그 밖의 줄은 메모 |
| `### 출처` | `[이름](주소)` 를 한 줄에 나열 |
| `### 확인 필요` | 빨간 점선 상자 (칸 밖, 장에 직접 붙는 경고) |

주제의식·영상·핵심 내용·기본 정보·질문 초안이 아닌 칸은 화면에서 "원자료"로 접힌다.

### 칸 안에 쓰는 것

| 표기 | 결과 |
| --- | --- |
| `- 이름 :: 설명` | 정보 표 (모든 줄이 ` :: ` 를 가질 때) |
| `- 항목` / `1. 항목` | 목록 / 번호 목록 |
| `> 인용문` 다음 줄 `> — 출처` | 인용과 출처 |
| `> [!확인] 내용` | 칸 안의 확인 필요 상자 |
| `\| 표 \| 머리 \|` | 표. 칸 안의 `\|` 글자는 `\\|` 로 쓴다. `●` `–` 만 있는 칸은 가운데 정렬. |
| ```` ``` ```` 으로 감싼 줄 | 수식 상자. `**이름**` 은 강조. |
| `![설명](그림 경로 "캡션")` 을 줄마다 | 그림 묶음. 끝에 `{.px}` 를 붙이면 픽셀을 살려 확대. |
| 문단 끝에 `{.say}` | 큰따옴표가 붙는 발언. `{.say .lead}` 는 조금 작게, `{.mono}` 는 고정폭. |
| `::: chain` … `:::` | `- 날짜 \| 말` 을 화살표로 이은 흐름 |
| `::: lens 제목` … `:::` | `1. **말** 영문` 키워드 판 (부 바로 아래) |

줄 안에서는 `**굵게**`, `==빨강 강조==`, `` `코드` ``, `[글자](주소)` 를 쓴다. `<small>`, `<em>` 같은 HTML 태그도 그대로 통한다.

표지는 `::: cover` 블록, 회고의 큰 문장은 `::: thesis` 블록에 있다. 회고 표는 각 장의 `회고:` 줄과 주제의식에서 자동으로 만들어진다.
